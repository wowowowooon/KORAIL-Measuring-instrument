# 측정 원리

## 기하 구성

두 레이저 거리센서가 **같은 회전축**에 X자로 장착되어 있고, 손으로 돌려 좌·우 레일 두정면을 각각 겨눕니다.
회전축(꼭짓점)과 두 착점이 삼각형을 이룹니다.

```
             O  (회전축 = 꼭짓점)
            /|\
         a / | \ b
          /  |h \
         /   |   \
   좌 A ●────F────● B 우
        |<-x->|
        |<--- D --->|
```

| 기호 | 의미 | 성격 |
|---|---|---|
| D | 두 착점 사이 거리 (궤간 1435 mm) | 고정값 |
| a | 좌 레이저 측정 거리 \|OA\| | 측정값 |
| b | 우 레이저 측정 거리 \|OB\| | 측정값 |
| h | 꼭짓점 O에서 레일면까지 수직 거리 | 구하는 값 |

세 변(SSS)이 정해지면 삼각형이 하나로 정해지므로 **각도는 필요 없습니다.**
레이저 각도를 손으로 바꿔도, 장치가 한쪽으로 치우쳐도 계산식은 그대로입니다.

## 유도

꼭짓점에서 밑변에 내린 수선의 발을 F, |AF| = x 라고 하면

```
a² = x² + h²
b² = (D − x)² + h²
```

두 식을 빼서 정리하면

```
x = (a² − b² + D²) / (2D)
h = √(a² − x²)
```

- a = b 이면 x = D/2 (꼭짓점이 정중앙 위)
- a ≠ b 이면 x 가 치우친 만큼 반영되어 그대로 수직 높이가 나옵니다.

꼭짓점의 좌우 치우침 `y = x − D/2` 도 함께 계산합니다(정렬 확인용, + = 오른쪽).

### 예시

a = 1200, b = 1120, D = 1435 mm 이면

```
x = (1200² − 1120² + 1435²) / 2870 = 782.2 mm   → y = +64.7 mm
h = √(1200² − 782.2²)               = 910.1 mm
```

## 유효 조건

`h² = a² − x² > 0` 이어야 삼각형이 성립합니다. 이는 삼각부등식 `a + b > D`, `|a − b| < D` 와 같습니다.
성립하지 않으면 한쪽 레이저가 레일이 아닌 곳을 찍었거나 0점 오프셋이 맞지 않은 것이므로 `TRI NG` 로 표시하고 높이를 내지 않습니다.

## 오차 특성

높이는 측정 거리 오차에 대해 다음과 같이 민감합니다.

```
∂h/∂a ≈ a / h        (대칭 배치 기준)
∂h/∂D ≈ −D / (4h)
```

| 높이 h | 거리 1 mm 오차 → 높이 오차 |
|---|---|
| 900 mm | 약 1.3 mm |
| 300 mm | 약 2.6 mm |
| 100 mm | 약 7 mm |

- 높이가 낮을수록 오차가 커지므로 실제 사용 높이(연결기 높이 약 880 mm) 근처에서 보정합니다.
- 착점 간격이 D 와 10 mm 다르면 높이는 약 4 mm 달라집니다. 레이저가 레일의 같은 위치(예: 궤간 측 모서리)를 겨누도록 하고, 다른 위치를 겨눈다면 그 간격을 `BASE_MM` 으로 둡니다.
- 센서 0점이 회전축과 일치하지 않으면 측정 거리가 짧게 나와 낮은 높이에서 삼각형이 성립하지 않습니다. 오프셋은 [보정 문서](calibration.md)대로 맞춥니다.

## 각도 기반 방식과의 비교

초기 설계안은 레이저 장착각 θ 를 고정값으로 두고 `h = d·cosθ` 계열로 높이를 구하는 방식이었습니다.

| | 장착각 기반 | 밑변 기반 (채택) |
|---|---|---|
| 필요한 값 | θ, a, b | D, a, b |
| 각도 오차 영향 | 1° 당 약 13 mm | 없음 |
| 손으로 각도 조정 | 매번 θ 재보정 필요 | 그대로 측정 가능 |

각도를 현장에서 손으로 맞추는 구조이므로, 각도를 변수에서 없앨 수 있는 밑변 기반 방식을 채택했습니다.
